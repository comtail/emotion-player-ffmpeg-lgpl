# EMOTION Player – demo playlist

Fictional demo content for testing EMOTION Player (e.g. by app reviewers):

- Playlist: https://comtail.github.io/emotion-player-ffmpeg-lgpl/demo/demo.m3u
- Programme guide (XMLTV): https://comtail.github.io/emotion-player-ffmpeg-lgpl/demo/epg.xml

All channel names, film and series titles are invented. Videos are abstract colour gradients generated
with FFmpeg; channel logos were generated; film artwork uses freely licensed photos from Unsplash
(via picsum.photos, Unsplash License) with invented titles. No third-party TV, film or series content.
