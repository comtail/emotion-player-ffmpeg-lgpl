2. Funktionsweise und lokale Daten

EMOTION Player ist ein Medienplayer für Quellen, die Sie selbst hinzufügen, etwa M3U-Playlists oder Xtream-kompatible Zugänge. Zu den hierfür verarbeiteten Informationen können Serveradressen, Zugangsdaten, Medienlisten, Programmführer, Logos, Cover, Favoriten, Wiedergabepositionen und Einstellungen gehören. Diese Daten werden für die Funktionen der App auf dem Endgerät verarbeitet.

Nach der derzeitigen technischen Beschreibung werden Zugangsdaten lokal verschlüsselt gespeichert. Die konkrete Verschlüsselungsimplementierung, Backup-Ausschlüsse und Löschfunktionen müssen vor Veröffentlichung anhand des ausgelieferten Builds bestätigt werden.

3. Verbindungen zu Medienquellen

Beim Abrufen von Playlist- oder Xtream-Daten, EPG-Informationen, Streams, Senderlogos und Covern stellt die App Verbindungen zu den von Ihnen eingetragenen oder durch Ihre Medienquelle angegebenen Servern her. Dabei erhalten die angesprochenen Server technisch bedingt insbesondere die IP-Adresse Ihres Anschlusses und die jeweils angefragten URLs sowie gegebenenfalls zur Authentifizierung erforderliche Zugangsdaten. Die Betreiber dieser Server können eigene Datenschutzregeln anwenden.

Bei unverschlüsselten HTTP-Verbindungen besteht das Risiko, dass Daten einschließlich Zugangsdaten von Dritten auf dem Übertragungsweg mitgelesen werden können.

Beispiel-Inhalte (optional): Wenn Sie „Beispiel-Inhalte ansehen“ antippen, lädt die App eine Beispiel-Playlist mit frei lizenzierten Filmen und Musik von GitHub Pages (comtail.github.io) und legt sie als Quelle an. Die Vorschaubilder kommen ebenfalls von comtail.github.io, die Video- und Audiodateien von github.com mit Weiterleitung auf release-assets.githubusercontent.com bzw. objects.githubusercontent.com. Alle diese Server betreibt die GitHub, Inc. (Datenschutzerklärung: docs.github.com/site-policy/privacy-policies). Sie erhalten dabei technisch bedingt Ihre IP-Adresse, die Kennung der App und die abgerufene Adresse. Ohne dieses Antippen findet keine Verbindung statt. Die Beispiel-Quelle können Sie wie jede andere Quelle wieder entfernen.

4. Externe Player

Wenn Sie eine Wiedergabe in einer extern installierten Player-App wählen, kann EMOTION Player die Medienadresse sowie gegebenenfalls einen Medientitel an die ausgewählte App übergeben. Insbesondere Xtream-Stream-Adressen können Zugangsdaten enthalten. Der externe Player kann diese Informationen eigenständig verarbeiten oder speichern. Vor einer sensiblen Übergabe soll die App darüber informieren; die tatsächliche Umsetzung ist Bestandteil der technischen Release-Prüfung.
