2. Funktionsweise und lokale Daten

EMOTION Player ist ein Medienplayer für Quellen, die Sie selbst hinzufügen, etwa M3U-Playlists, Xtream-kompatible Zugänge oder einen eigenen Sat-Receiver mit Enigma2 (OpenWebif). Zu den hierfür verarbeiteten Informationen können Serveradressen, Zugangsdaten, Medienlisten, Programmführer, Logos, Cover, Favoriten, Wiedergabepositionen und Einstellungen gehören. Diese Daten werden für die Funktionen der App auf dem Endgerät verarbeitet.

Nach der derzeitigen technischen Beschreibung werden Zugangsdaten lokal verschlüsselt gespeichert. Die konkrete Verschlüsselungsimplementierung, Backup-Ausschlüsse und Löschfunktionen müssen vor Veröffentlichung anhand des ausgelieferten Builds bestätigt werden.

In der App für Samsung-Smart-TV (Tizen) werden Zugangsdaten im app-eigenen Speicher des Fernsehers abgelegt, auf den andere Apps keinen Zugriff haben. Eine zusätzliche Verschlüsselung findet dort nicht statt, weil das System hierfür keine geeignete Schnittstelle bereitstellt.

3. Verbindungen zu Medienquellen

Beim Abrufen von Playlist- oder Xtream-Daten, EPG-Informationen, Streams, Senderlogos und Covern stellt die App Verbindungen zu den von Ihnen eingetragenen oder durch Ihre Medienquelle angegebenen Servern her. Dabei erhalten die angesprochenen Server technisch bedingt insbesondere die IP-Adresse Ihres Anschlusses und die jeweils angefragten URLs sowie gegebenenfalls zur Authentifizierung erforderliche Zugangsdaten. Die Betreiber dieser Server können eigene Datenschutzregeln anwenden.

Sat-Receiver (Enigma2): Wenn Sie einen Receiver hinzufügen, verbindet sich die App direkt mit der von Ihnen angegebenen Adresse, in der Regel in Ihrem Heimnetz. Dabei werden Senderlisten, Programminformationen, Senderlogos, Aufnahmelisten und Streams abgerufen und gegebenenfalls die von Ihnen eingetragenen Zugangsdaten an den Receiver übermittelt. Ein Server von Corevant Software ist daran nicht beteiligt.

Bei unverschlüsselten HTTP-Verbindungen besteht das Risiko, dass Daten einschließlich Zugangsdaten von Dritten auf dem Übertragungsweg mitgelesen werden können.

Beispiel-Inhalte (optional): Wenn Sie „Beispiel-Inhalte ansehen“ antippen, lädt die App eine Beispiel-Playlist mit frei lizenzierten Filmen und Musik von GitHub Pages (comtail.github.io) und legt sie als Quelle an. Die Vorschaubilder kommen ebenfalls von comtail.github.io, die Video- und Audiodateien von github.com mit Weiterleitung auf release-assets.githubusercontent.com bzw. objects.githubusercontent.com. Alle diese Server betreibt die GitHub, Inc. (Datenschutzerklärung: docs.github.com/site-policy/privacy-policies). Sie erhalten dabei technisch bedingt Ihre IP-Adresse, die Kennung der App und die abgerufene Adresse. Ohne dieses Antippen findet keine Verbindung statt. Die Beispiel-Quelle können Sie wie jede andere Quelle wieder entfernen.

4. Eingabe per Handy (QR-Code, optional)

In der TV-App können Sie Playlist-Adressen und Zugangsdaten bequem am Smartphone eingeben. Dafür zeigt der Fernseher einen QR-Code an. Nach dem Scannen öffnet sich auf Ihrem Smartphone eine Eingabeseite unter emotion-qr.emotionplayer.workers.dev. Dieser Vermittlungsdienst wird von Corevant Software betrieben und läuft auf der Plattform Cloudflare Workers der Cloudflare, Inc., 101 Townsend St., San Francisco, CA 94107, USA, die als Auftragsverarbeiter für uns tätig ist.

Ihre Eingaben werden bereits auf dem Smartphone verschlüsselt (AES-GCM). Der Schlüssel ist nur im QR-Code enthalten und wird nicht an den Server übertragen. Der Dienst erhält und speichert daher nur einen zufälligen Code und den verschlüsselten Inhalt. Corevant Software und Cloudflare können den Inhalt nicht lesen. Der Fernseher holt die Daten einmalig ab; danach werden sie gelöscht, spätestens jedoch nach 10 Minuten.

Beim Aufruf verarbeitet Cloudflare technisch bedingt Verbindungsdaten wie die IP-Adressen von Fernseher und Smartphone, Zeitpunkt, aufgerufene Adresse und Browserkennung, um die Seite auszuliefern und vor Missbrauch zu schützen. Eigene Zugriffsprotokolle des Dienstes haben wir abgeschaltet. Die Eingabeseite verwendet keine Cookies, keine Analyse- und keine Trackingdienste. Ohne Aufruf der Funktion „Mit dem Handy eingeben“ findet keine Verbindung zu diesem Dienst statt.

Rechtsgrundlage ist Art. 6 Abs. 1 lit. b DSGVO (Bereitstellung der von Ihnen gewünschten Funktion) sowie für die Sicherheitsverarbeitung Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an einem sicheren Betrieb). Eine Übermittlung in die USA ist möglich; Cloudflare, Inc. ist nach dem EU-US Data Privacy Framework zertifiziert, ergänzend gelten die Standardvertragsklauseln der EU-Kommission. Weitere Informationen: www.cloudflare.com/privacypolicy.

5. Externe Player

Wenn Sie eine Wiedergabe in einer extern installierten Player-App wählen, kann EMOTION Player die Medienadresse sowie gegebenenfalls einen Medientitel an die ausgewählte App übergeben. Insbesondere Xtream-Stream-Adressen können Zugangsdaten enthalten. Der externe Player kann diese Informationen eigenständig verarbeiten oder speichern. Vor einer sensiblen Übergabe soll die App darüber informieren; die tatsächliche Umsetzung ist Bestandteil der technischen Release-Prüfung.
